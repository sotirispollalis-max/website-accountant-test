# A&A TAX EXPERTS — Λογιστικό & Φοροτεχνικό Γραφείο (πρόταση ιστοσελίδας)

Vanilla HTML / CSS / JavaScript — χωρίς build, χωρίς εξαρτήσεις (ίδια αρχιτεκτονική με το `../logistiko`).
Προβολή: `python3 -m http.server` στον φάκελο και άνοιγμα του `http://localhost:8000`.

```
index.html     κύρια σελίδα (hero, γραφείο, υπηρεσίες, επιχειρήσεις, γιατί εμείς, διαδικασία, άρθρα, FAQ, επικοινωνία)
legal.html     Απόρρητο / Cookies / GDPR (πρότυπο — χρειάζεται νομικό έλεγχο)
css/style.css  design tokens στο :root (χρώματα, spacing, γραμματοσειρές)
js/config.js   ΣΤΟΙΧΕΙΑ ΠΕΛΑΤΗ: διεύθυνση, τηλέφωνο, email, ωράριο, WhatsApp, endpoint φόρμας, χάρτης
js/i18n.js     GR/EN — τα ελληνικά στο HTML, τα αγγλικά χειρόγραφα στο λεξικό EN
js/main.js     μενού, scroll, parallax, reveal, φόρμα, χάρτης
```

## Τι πρέπει να συμπληρωθεί (placeholders σε αγκύλες `[...]`, με διακεκομμένη υπογράμμιση)
1. `js/config.js`: διεύθυνση, τηλέφωνο (+`phoneHref`), email (+`emailHref`), ωράριο, `mapQuery`.
   Τα ίδια εφεδρικά κείμενα υπάρχουν στο `index.html` (για SEO/χωρίς JS).
2. **WhatsApp**: βάλτε αριθμό στο `whatsapp` — μέχρι τότε το κουμπί δεν εμφανίζεται.
3. **Φόρμα**: βάλτε `formEndpoint` (Formspree/Formspark/Web3Forms ή δικό σας backend).
   Χωρίς endpoint και χωρίς `emailHref` η φόρμα δουλεύει σε *λειτουργία επίδειξης*: επικυρώνει αλλά **δεν στέλνει** και το λέει ξεκάθαρα.
   Αντι-spam: honeypot + έλεγχος χρόνου συμπλήρωσης + συγκατάθεση. Για παραγωγή προτείνεται και
   Cloudflare Turnstile / reCAPTCHA στο backend (server-side έλεγχος).
4. `example.gr` → πραγματικό domain (canonical, og:url, og:image, JSON-LD στο `index.html`).
5. `legal.html`: επωνυμία, ΑΦΜ, Δ.Ο.Υ., διεύθυνση, πού καταλήγει η φόρμα — και νομικός έλεγχος.
6. **Άρθρα**: 3 placeholder κάρτες («Σύντομα») — αντικαταστήστε με πραγματικά άρθρα ή αφαιρέστε την ενότητα.
7. Απαντήσεις FAQ και περιγραφές υπηρεσιών: ελέγξτε ότι ταυτίζονται με όσα όντως προσφέρει το γραφείο.
8. Λογότυπο: το μονόγραμμα είναι CSS (`.mark`) + `img/favicon.svg` — αντικαταστήστε με το επίσημο.

## Εικόνες
Φωτογραφίες Unsplash (δωρεάν εμπορική χρήση) ως **προσωρινές**: `hero.webp` (αρχιτεκτονική), `office*.webp`; .

## GDPR
Γραμματοσειρές/εικόνες τοπικά, χωρίς cookies/analytics. Ο χάρτης Google φορτώνει μόνο μετά από κλικ του επισκέπτη.
Η γλώσσα αποθηκεύεται στο localStorage του browser (όχι cookie). Αν προστεθεί Analytics, χρειάζεται banner συγκατάθεσης.

## Δεν υπάρχουν πλασματικά στοιχεία
Κανένα testimonial, βραβείο, έτη εμπειρίας, αριθμοί πελατών, ονόματα ή πιστοποιήσεις.

## Αξιολογήσεις πελατών & διαδραστικότητα
- **Αξιολογήσεις**: προστίθενται ΜΟΝΟ στο `reviews: []` του `js/config.js` (πραγματικές, με συναίνεση πελάτη).
  Ο μέσος όρος και το πλήθος υπολογίζονται αυτόματα. Όσο η λίστα είναι κενή εμφανίζονται ουδέτερα placeholders — δεν υπάρχουν πλασματικά αστέρια.
- **Φόρμα αξιολόγησης**: στέλνεται στο ίδιο `formEndpoint` με `type: "review"` (χωρίς endpoint = λειτουργία επίδειξης, δεν στέλνει).
  Δεν δημοσιεύεται αυτόματα: ο ιδιοκτήτης ελέγχει και προσθέτει χειροκίνητα στο `reviews`.
- **Διαδραστικά στοιχεία**: επιλογέας προφίλ («Βρείτε τη λύση σας»), progress bar κύλισης, κουμπί «πάνω», spotlight στις κάρτες υπηρεσιών, carousel αξιολογήσεων.

## Κινήσεις κύλισης (live scroll)
Hero που ξεθωριάζει, παράλλαξη εικόνων (`data-parallax`), reveals από αριστερά/δεξιά/zoom, clip-path στη φωτογραφία, γραμμές διαδικασίας που σχεδιάζονται,
header που κρύβεται προς τα κάτω και επανεμφανίζεται προς τα πάνω, και πλευρική πλοήγηση με τελείες (≥1320px).
Όλα σβήνουν με `prefers-reduced-motion`. Responsive: έλεγχος σε 360 / 768 / 1024 / 1920px, landscape κινητών, safe-areas iOS, στόχοι αφής 44px.
